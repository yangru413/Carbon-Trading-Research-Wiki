# Word／PDF 簡短撰寫指南

由使用者自行撰寫 Word，再匯出 PDF。建議約 2～3 頁，非教師規定。

1. **專案簡介**：碳交易配對研究指南的目的、使用對象、CM03 第二年主線及白話、可追溯的內容特色。
2. **實際成果與連結**：填入 GitHub Repository、發布後實際可用的網站網址，放首頁與文章截圖；未部署不可用猜測網址充數。
3. **規則如何協助延伸**：解釋 AGENTS.md 的頁面格式、檔案規則、引用與驗收；以基因演算法新頁為例，列正文、登錄、卡片、書目與建置流程。
4. **重用與限制**：說明版型、卡片與新增程序可沿用；研究內容與引用須重新核對。區分已有內容、未完成章節與沒有執行的實驗。

流程與來源的實際證據見 ga-page-proof.md。匯出後檢查中文字型、圖片清晰度、連結及分頁。最後繳交 **PDF＋AGENTS.md**；Word 原稿自行保留。
