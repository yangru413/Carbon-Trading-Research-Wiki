## 1. 專案定位

- 名稱：碳交易配對演算法研究 Wiki（Carbon Trading Matching Research Wiki）。
- 用途：任何研究者可循序閱讀或按主題查閱的繁體中文研究指南，保留零背景也可理解的解釋，不使用課程預告、菜鳥身分假設或指揮語氣。
- 背景：EU ETS／EUA。研究重心：CM03 第二年 Theme 2 — Development of ET System (ETS) with Multiple Objectives。
- 第一年企業永續預測、第三年 HRS 作脈絡與延伸，不取代第二年的主線。
- RAG Notebook 僅屬技術發想；不必加入 RAG、LLM API、後端、金鑰、登入、個人化進度或完整資料庫。

## 2. 章節與卡片互動

章節順序：研究脈絡與問題 → 碳交易基礎 → 交易配對模型 → 多目標最佳化 → 研究資料 → 求解方法與演算法 → 實驗設計與評估。CM03 計畫解讀有獨立入口。

首頁採使用者核准的方案 B，結合 Wiki 主題卡片：
- 點主題標題進入章節；點內文區展開／收合至少三張延伸子卡片。
- 子卡片插入同一卡片流，後續卡片往後排，超出當列寬度就換行；不是浮層，也不是疊在正文上。
- 子卡片標題進入已有延伸頁；沒有內容時只顯示待整理狀態，沒有假連結。
- 使用原生連結與按鈕，aria-expanded／aria-controls 配對，鍵盤與觸控可操作。停用 JavaScript 時延伸可直接展開閱讀。
- 每章至少三個補充項目由 data/topics.json 管理，可增加，不以三個為上限；內容狀態應與實際頁面一致。
- 導覽名稱使用「研究資料」指資料集與資料庫；文件引用另以「參考文件／參考文獻」標示。

### 7.1 研究內容範圍

#### 3.1 主題入口
網站長期知識架構規劃以下主題；本次 12 小時初版的實作範圍以本文件第 5 節為準，不要求每個主題各建獨立頁面：

1. **碳交易基礎**：碳排放、碳權／排放配額、總量管制與交易、買方與賣方、碳定價。
2. **EU ETS 與制度**：制度沿革、交易階段、配額分配、拍賣、履約、監測／申報／查證（MRV）、Union Registry。
3. **資料與碳價**：EUTL、資料欄位、交易紀錄、價格資料來源、價格口徑、資料清理與時間配對。
4. **數學與統計基礎**：集合、函數、向量、矩陣、機率統計、標準化、權重、目標函數、限制式及必要的最佳化基礎。
5. **交易配對模型**：買賣雙方、供需、配對決策、交易量、成本／收益、限制條件與多目標建模。
6. **多目標最佳化與演算法**：Pareto 最佳解、支配關係、族群式演化、參考向量及 CM03 第二年涉及的方法。
7. **研究實作指南**：資料準備、模型建構、權重取得、實驗設計、比較基準、評估指標、結果解讀及研究限制。
8. **CM03 計畫解讀中心**：獨立入口，逐段解讀計畫並以第二年 Theme 2 為主線。

主題可隨內容成長調整，但不得為了增加分類而建立空洞頁面。

#### 3.2 CM03 計畫解讀中心
必須有獨立頁面或專區，不能只把 CM03 混在一般知識文章中。

專區應：
- 先介紹計畫整體動機與三個 Theme 的關係。
- 清楚標示 Theme 1（第一年）、Theme 2（第二年）、Theme 3（第三年）。
- 將 Theme 2 設為主要閱讀路徑及最醒目的內容。
- 對已納入網站的重要方法說明「原文在說什麼、白話意思、為什麼需要、前置知識、研究中如何使用、目前仍有哪些問題」；初版以核心方法導讀為限，其餘依本文件第 5 節後續擴充。
- 連結到一般知識庫的基礎文章，避免同一知識重複維護。
- 區分「計畫書原本提出的內容」與「後續補充的文獻或 Agent 解讀」。

#### 3.3 CM03 第二年研究主線
依使用者提供的 CM03 文件，第二年 Theme 2 的主題是多目標排放交易系統（ET System / ETS）。下列為長期整理方向，須先核對原始文件；初版提供本文件第 5 節所列核心說明，不要求完整推導、演算法實作或實驗：
- 買方與賣方的交易配對問題。
- 買方低成本、賣方高利潤，以及計畫所列的其他目標。
- 永續發展聲譽（sustainable development reputation）如何納入交易／配對考量。
- 基礎排放交易配對問題與進階多目標問題的差異。
- Hungarian algorithm 作為基礎問題的比較方法。
- EMOBET 的設計概念與流程。
- Adaptive Reference Vectors（自適應參考向量）的用途。
- Pareto-based、decomposition-based、indicator-based 多目標演算法比較；計畫列出的比較方法包括 NSGA-III、REVA、ARMOEA。
- 計畫提出的評估面向，包括 IGD、執行時間、買賣配對率及各目標函數的 Pareto 解分布。
- 參數分析與消融實驗（ablation experiment）的目的。
- 第二年與第一年永續企業預測模型、第三年階層式粗糙集（HRS）之間的關聯。

注意：上列是計畫內容的整理方向，不代表所有方法已完成實驗或已取得特定成效。若 CM03 文件未提供數值或結論，必須明確標示「計畫文件未提供」或「待查證」。

#### 3.4 權重取得與研究實作
權重問題是重要的研究學習痛點，應規劃專門內容；可併入多目標最佳化章節，不必另建專區：
- 權重代表什麼，以及為何不同目標／指標需要權重。
- 區分「目標函數權重」、「參考向量權重」、「屬性權重」等不同概念；不得因都叫權重就混為一談。
- 解釋權重可能來自文獻、專家判斷、資料驅動方法、模型參數或演算法內部更新；必須先確認研究問題再選方法。
- 介紹可行方法時，列出所需資料、前提、優缺點、可重現性及是否符合 CM03。
- 不可在未確認計畫公式與研究設計前，擅自指定一組權重當成正式研究設定。

### 7.2 EU ETS／EUTL 資料規則

#### 4.1 EU ETS 選擇理由
網站應有一張卡片或一篇文章說明為何以 EU ETS 為主要研究體系。內容應以可查證的制度證據支持，例如：
- 制度啟動時間與發展階段；
- 總量管制與配額交易架構；
- 監測、申報、查證及履約制度；
- 配額拍賣、免費分配及市場監管；
- Union Registry／EUTL 的資料與登記制度；
- 官方公開資料與市場價格資料的可取得性。

不得只用「歐盟最成熟」等主觀描述。若使用「成熟」、「完整」等判斷，必須說明判斷標準及支持證據，也要交代制度限制。

#### 4.2 EUTL 資料限制
- 必須依使用者提供的 EUTL 資料庫說明文件確認欄位與定義。
- 不可假設 EUTL 每筆配額轉移紀錄都包含實際成交價。
- 必須區分配額登記／轉移紀錄與市場買賣合約／交易所成交紀錄。
- 不可把登記系統的轉移時間直接當成交易雙方議價或成交時間，除非有可靠來源證明兩者關係。
- 對網站實際介紹或使用的欄位說明其定義、單位、可用性、限制與研究用途；初版不要求完整欄位辭典。

#### 4.3 碳價來源與價格口徑
優先尋找免費、可合法公開取得且可追溯的資料。每個價格數值必須記錄：
- 市場／交易體系（例如 EU ETS）。
- 商品或合約種類（例如 EUA 現貨、特定到期月份期貨、拍賣配額）。
- 價格類型（開盤、收盤、結算、逐筆成交、VWAP、拍賣結算價等）。
- 日期與時間、時區。
- 價格單位與幣別（例如 EUR/tCO2）。
- 資料來源、下載／查詢日期及原始網址。
- 資料是否免費、是否有延遲、是否有使用限制。

不得把不同價格口徑混為一談。特別是：
- 期貨價格不等於現貨價格。
- 每日收盤價不等於全天成交均價。
- 拍賣結算價不等於所有二級市場交易價格。
- 市場價格代理值不等於 EUTL 某筆轉移的實際成交價。

#### 4.4 交易時間與碳價連結：待研究議題
這是後續研究問題，初期網站先建立概念卡與研究問題，不得在證據不足時下結論。

需要調查：
1. 是否能取得一定數量的 EUA 買賣合約或逐筆成交資料。
2. 合約／成交資料是否包含交易日期時間、價格、數量、到期月份及交易所資訊。
3. EUTL 轉移紀錄的時間與市場成交時間是否可連結；若不能，需明確說明。
4. 文獻或市場研究如何選取交易前可觀察的價格：前一日收盤、當日開盤、盤中價格、VWAP、近幾日平均等。
5. 如何避免 Look-ahead Bias（前視偏誤）：不可用交易決策時間之後才出現的資訊，假裝成當時已知價格。
6. 若逐筆合約不可取得，可否使用日價格作為代理變數，並說明其假設與限制。

所有時間配對方法都要說明其時間先後關係、時區、資料頻率及適用情境。不可將研究假設寫成已被文獻證實的通則。

#### 4.5 無法取得資料時的處理順序
1. 先找官方免費資料。
2. 再找交易所公開資料、研究機構或可信的免費資料平台。
3. 再找可重現的學術研究資料或附錄。
4. 若仍無法取得，才考慮以文獻價格或明確假設估計。
5. 估計值必須標示「估計／代理／假設」，不可偽裝成真實成交價。
