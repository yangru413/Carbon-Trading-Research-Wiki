# 固定頁框與換頁穩定性檢查：v1.0.2

日期：2026-11-23。延續已推送v1.0.1及使用者追加要求，固定每頁大小及標題位置，不修改教學內容。

## 本次修改
- 單頁模式填滿視窗，隱藏重複的網站頁首頁尾，保留回Wiki與全文按鈕。
- 每頁使用一致的標題、問題、內容、結論與來源區域；標題靠上對齊，不因單行／多行而垂直置中移動。
- 移除換頁時的整頁scrollIntoView，只重設新頁中間閱讀區；側邊箭頭、跳頁與頁碼維持位置。
- 第一頁圖與兩點說明桌機並排；GA／ACO也並排。手機直排，內容可在中間區域捲動，標題與頁框不跟著動。
- 全文閱讀與無JS時恢復完整長頁；列印顯示全部內容，不截掉中間捲動區。

## 實測方式
以Microsoft Edge檢查1440×1000、1280×720、390×844，每種10頁，共30組：
1. 對照每頁框寬、框高、框頂、標題頂及問題頂，與同一視窗第一頁相差小於1px。
2. 將中間閱讀區捲到底，標題位置保持；切頁、跳頁與鍵盤均不造成整頁位移。
3. 打開P5答案後，標題仍在同一位置；可用Enter收起。
4. 驗證圖片解碼、各頁來源、完整節點外框、同頁圖示唯一、懶人包／產出成果標籤、首尾、全文、列印與無JS。
