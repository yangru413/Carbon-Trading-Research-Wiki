## 來源與製作方式
新增七張本站自製SVG（配對、GA、ACO、可行性、三張交接），另四張手機重排版本。由scripts/draw-slide-illustrations.py生成，沒有重製論文原圖；圖說交代依據與假設。
GA字串與最多兩項的限制沿用Wiki教學例子，不是CM03正式模型；ACO路線純示意，不摘錄論文效能；供需A=(8,4)合計12且均不超額、B=(11,1)合計12但乙超過10，僅驗證教學算術。
