## 階段、產物與退回規則

| 階段 | 工作與產物 | 檢查／失敗退回 |
| --- | --- | --- |
| 01 確認目標 | 確認讀者、主題、深度與學習成果 | 初學者能懂、聚焦研究如何進行；不清楚先討論 |
| 02 查Wiki與來源 | 先查索引再讀正文、引用；整理主張、限制與圖解 | 區分事實／計畫／假設／結果，核對圖文來源及使用權限；缺依據繼續閱讀 |
| 03 確認大綱 | 頁序、主旨與教學問題；保存大綱 | 無缺漏或重複，使用者確認後才寫逐頁稿；不通過留在03調整 |
| 04 寫逐頁稿 | 解釋、例子、概念圖、引用與結論 | 忠於Wiki且解釋足夠，演算法等抽象概念有圖；缺依據回02，內容不足在04補寫 |
| 05 生成HTML | 依稿排版與操作，保留返回Wiki入口 | 對照下方版面規則；內容不足回04，介面問題在05修正 |
| 06 實測與回歸 | 桌機／手機截圖、量測、操作及人工目視 | 內容失敗回04、介面失敗回05；修改後重測06的原問題及受影響項目 |
| 07 試讀與發布 | 使用者試讀、定案；版本與檢查紀錄 | 意見依性質回02／04／05，再做06；依當批授權推送，確認公開內容與本機一致 |

Loop是「發現問題→回對應步驟修改→重新檢查」。圖中的退回箭頭是條件規則，不代表每次都觸發；只將實際發生的錯誤寫入紀錄。

## 每頁必查

- 保留定案的頁序、教學內容與排版；補充來自Wiki，不以重複句湊篇幅。
- 節點有完整框線與貼切圖示，同頁圖示不重複，不額外加數字或小標。大張graph採01–07，由上往下，無副標題／最底小備註，只保留一句loop。
- PC在100%縮放下頁框、標題與問題位置固定；圖文／來源完整顯示、不遮擋。以並排、錯開與適度縮放解決過高，禁止裁切或縮到難讀。
- 所有裝置禁止頁內捲動區；答案展開可延長整頁。手機自然直排可捲整個文件，但不能水平溢出。
- 演算法等概念有示意圖及解釋；來源、改繪方式、假設與教學數字清楚。圖片文字略小於內文但可讀，不忽大忽小。
- 圖解旁註放圖片正下方置中、略小字，不必加圓點；圖說貼近圖片。
- 圖文、段落與卡片的視覺重量平均、間距適當；避免緊貼或大片空疏。先補必要解釋／重排，仍不足再補相關資料圖片並附來源及核對公開權限。
- 練習題清楚提示可點開答案、支援鍵盤；結論標「懶人包」，研究交付標「產出成果」。

## 執行與記錄

```powershell
python scripts/build-demo.py
python scripts/check-demo.py
python scripts/check-slides.py
```

瀏覽器檢查需Playwright與Edge，本機工具在.tools/vendor且不公開。PC採1280×720、1366×768、1440×900、1920×1080共40頁，加390×844手機共50頁。程式檢查PC固定幾何、內容／來源溢出、無內部捲動、完整框線、同頁圖示唯一、圖片與來源入口，以及箭頭／鍵盤／跳頁／答案／全文／列印／深層連結／無JS。手機不要求不同長度內容等高。

人工必須逐頁核對主張、圖解、圖字可讀、留白、對齊及視覺重量。程式通過不等於美感或學術審查。JSON存docs/validation/slides-v版本.json，截圖暫存.work/preview；--draft只寫私人暫存，保留既有版本紀錄。

重畫圖：scripts/render-slides-workflow.py產生SVG，再用scripts/export-workflow-png.py輸出高解析PNG。圖為本站原創程式繪製，無外部圖像；呈現簡報製作規則，不冒充研究實驗成果。
