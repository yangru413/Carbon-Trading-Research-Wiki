# Wiki 改造架構

日期：2026-11-21。這是待實作架構，不表示新頁面與 ingest 已完成。

## 雙入口
保留視覺與卡片，增加研究導讀；主題查閱可直接進文章。
導讀：研究問題 → 制度背景 → 資料理解與清洗 → 模型、價格與指標 → GA／ACO → 實驗評估 → 跨年度銜接。

## 頁面安排
| 主題 | 處理方式 |
| --- | --- |
| 研究引言、流程與方法論 | 更新研究脈絡，解釋各步輸入／輸出，區分計畫預期與實際成果 |
| 碳交易意義與起源 | 擴充基礎頁，連到研究問題 |
| EU ETS 與法規 | 獨立文章，區分 2020 樣本背景與現行制度 |
| 資料清洗與欄位 | 整合研究資料、交易 log，說明版本、欄位、時間與使用限制 |
| GA／ACO | 建議各自成篇；沿用 GA 有效內容，新增 ACO；詳細機制與應用按後續需要擴充 |

主要文章各 3–5 篇文獻；文獻摘要逐篇隨實際閱讀建立；比較與疑義放相關延伸入口，不公開私人研究進度。

## 後續順序與檢查迴圈
1. 本批完成規則與架構。
2. 提出候選來源，逐篇讀取、討論後整合；至少完成五篇實際 ingest。
3. 修改導讀及正文，保留網址，執行內容與技術 lint。
4. 從 Wiki 製作精簡 HTML 簡報；素材先確認再加入。
5. 依真實紀錄整理流程、檢查、反思與繳交大綱。

來源取得 → 查重與版本檢查 → 閱讀／主張整理 → 討論 → Wiki 整合／跨頁更新 → lint → 簡報 → 簡報檢查。
引用不足回到來源，矛盾回到比較，內容／版面失敗回到相應編輯。記錄實際退回與修正，不預先編寫反思。
